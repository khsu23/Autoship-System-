# Out-of-Stock Handling
Version: 1.0

## Shipment-day inventory check

On the scheduled ship day, inventory is checked before the order is released. If the selected item is unavailable, the shipment is delayed and a notification is recorded for the pet parent.

**Exception:** The subscription remains active; an out-of-stock delay is not a cancellation and does not remove Autoship savings eligibility.

## Replacement items

Chewy does not automatically substitute a different pet food flavor or size for an Autoship order without the pet parent's approval.
