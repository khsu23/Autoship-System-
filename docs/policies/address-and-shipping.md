# Address and Shipping Rules
Version: 1.0

## Address verification

Shipping addresses must include a recipient, street line, city, two-letter state, and valid US ZIP code. Apartment markers such as #4 are standardized to Apt 4.

**Exception:** An address that cannot be verified must be corrected before checkout can reserve inventory.

## Shipping changes

Pet parents can change their shipping address before their next order processes. Taxes are estimated from the destination ZIP code.
